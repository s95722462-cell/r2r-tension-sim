# 롤투롤 장력 시뮬레이터

2차 전지 롤투롤 라인(권출 → 구동 롤 → 권취)의 서보 장력 제어를 브라우저에서 물리 계산으로 돌려 보는 교육·검토용 시뮬레이터입니다.

**바로 열기:** https://s95722462-cell.github.io/r2r-tension-sim/

- 장력 제어 6방식 비교 (장력 센서 + 속도 / 댄서 / 토크 / 센서 없는 토크 / 이중 루프 / 관성 보상) — 미쓰비시 MELSEC iQ-F Roll to Roll FB 라이브러리(SH-082718)의 분류를 따름
- 지름 계산(두께 누적·회전비), 테이퍼, S자 가감속, 인터락(끊김·과장력·롤 소진)
- 댄서, 구동 롤 미끄럼(캡스턴 식 + 닙 가압), EPC 사행 보정, 롤 프레스 상·하 2모터 드룹
- 라인 프리셋: 기본 / 코터(구동 롤 3 + 건조로) / 롤 프레스, 구간별 목표 장력, 중간 롤 드로우 vs 장력 루프
- 필름: 동박 8µm, 알루미늄박 15µm, 분리막 16µm

수치는 일반값이며 실제 장비와 다를 수 있습니다. 설치 없이 `index.html` 하나로 동작하고(`engine.js` 내용 포함), `engine.js` 는 계산 엔진만 따로 둔 것으로 node 에서 `runScenario()` 로 시험할 수 있습니다.
