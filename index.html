메인 롤 · EPC

미끄럼: 메인 롤이 잡는 힘 = 낮은 쪽 장력 × (eμθ − 1) + 2 × μ × 닙 가압. 앞뒤 장력 차이가 이보다 크면 필름이 미끄러집니다.

운전

지름 변화 배속: 실제로는 롤 하나 감는 데 몇 시간 걸리므로, 짧은 시간에 지름 변화를 보려고 두께만 키워 계산합니다. 설정을 바꾸면 처음 상태로 돌아갑니다.

    계산 모델 설명 (PLC 로 옮길 때 참고)
    • 필름 스팬: 길이 L 사이 장력 변화 L·dT/dt = EA·(v뒤 − v앞) + T앞·v앞 − T·v뒤. E = 영률, A = 두께×폭. 동박 8µm·300mm 면 EA ≈ 264kN → 속도가 1% 어긋나면 장력이 약 2,600N 바뀜 (그래서 딱딱한 포일은 속도 제어가 어렵다).
    • 롤: J(D)·dω/dt = 토크 ± 장력×반지름 − 마찰. J 는 지름의 4제곱에 비례 (동박 300mm 롤 ≈ 176kg, J ≈ 2.1kg·m²).
    • 지름: 실제 지름은 한 바퀴마다 두께만큼 변함. PLC 계산값은 두께 누적식(시작 지름 입력 + 엔코더 회전수 × 두께) 또는 회전비식(라인 속도 ÷ 롤 회전 속도).
    • 서보: 속도 모드 = 앰프 속도 루프(20Hz), 토크 모드 = 토크 지령 + 속도 제한(라인 속도의 110%). 토크 한계 40N·m.
    • PLC: 2ms 주기로 S자 라인 속도 생성, 지름 계산, 장력 PID, 토크 계산, 인터락(장력 30% 미만 50ms → 비상 정지·릴 속도 제어 전환, 200% 초과 → 비상 정지, 권출 롤 소진).
    • 장력계: 잡음 ±0.2N, 5ms 필터.
    • 댄서(②⑤): 에어 실린더가 아래로 누르는 힘 F 로 장력 ≈ F/2. 댄서가 내려가면 스팬이 길어져 필름이 늘어남. 실린더 마찰 4N, 레귤레이터 응답 0.15초, 행정 ±60mm. 릴은 댄서 위치를 0 으로 맞추는 속도 제어(PI).
    • 메인 롤 미끄럼: 잡는 힘 = min(T앞, T뒤)·(eμθ−1) + 2·μ·닙 가압 (캡스턴 식). 넘치면 필름이 롤 위에서 미끄러지고 라인 속도가 흐트러짐.
    • EPC: 권출 스탠드를 옆으로 움직이는 방식. 엣지 센서는 권출에서 0.3m 뒤. 필름 가장자리는 스탠드 위치를 시간상수 (0.3m ÷ 라인 속도)로 따라감 → 멈춰 있으면 보정이 안 됨. 흔들림: 롤 한 바퀴 주기 0.3mm + 20초 주기 흐름 + 이음매 어긋남.
    • 롤 프레스: 상·하 롤이 필름을 물고 있어 한 몸처럼 돌아감. 지름이 조금만 달라도 두 속도 제어가 서로 반대로 싸움(한쪽 +, 한쪽 −). 드룹(미쓰비시 드룹 FB 방식) = 상 롤은 라인 속도 그대로 지키고, 하 롤만 (하 토크 − 상 토크) × 5%/정격만큼 속도 지령을 바꿔 부하를 나눔. 토크 값은 50ms 필터 (바로 쓰면 고속에서 발진).
    • 여러 롤 라인(3차): 구동 롤 사이마다 장력 구간. 기준 롤(속도 기준) 위쪽 구간은 위쪽 끝 축이, 아래쪽 구간은 아래쪽 끝 축이 맡음. 중간 롤 지령 = 라인 속도 × (1 + 앞뒤 구간 장력 차 ÷ EA) [드로우] + 가속도 × 서보 지연 [피드포워드] ± PI(구간 장력 오차) [장력 루프]. 프레스 뒤 롤은 압연 연신율만큼 더 빠르게. 건조로 아이들 롤은 베어링 마찰만큼 장력을 조금씩 올림.
